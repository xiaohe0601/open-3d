# Modra

[English](modra.md) · [连接方式](modra-connection-routes.zh-CN.md) · [隐私与故障排查](ai-privacy-and-troubleshooting.md)

Modra 是 Open 3D 的建模任务工作区，通过悬浮的 **Modra** 按钮打开，使用你配置的 AI 服务，不提供模型账号。

## 规划、构建和审查

- **规划**只允许场景查询与结构化计划，即使选择**自动批准**也不会生成预览或修改场景。
- **构建**可以建议整批建模命令。**请求批准**先显示预览，请查看受影响物体、有序命令及工具详情，再接受或拒绝整批更改。每批已接受更改都支持撤销。
- **按计划构建**基于当前场景和批准选项创建新任务。计划步骤的完成代表进度，不等于场景已经应用了更改。
- **自动批准**会应用成功的批次并继续执行，最多 20 批后暂停。失败时保留的部分建议仍需手动**保留更改**或**丢弃更改**；保留不会重新发送失败的请求。

手动编辑、撤销/重做、项目替换或写入权丢失会使旧预览失效。历史中的“已接受”不证明新加载的场景仍包含该效果。打开历史不会恢复场景或重放请求。

## 主动添加上下文

通过**引用物体**或**附加所选物体**添加稳定物体引用，最多 20 个。名称只是标签：重命名后仍会解析当前属性，但已删除或替换的物体会阻止发送，请移除或替换失效引用。

**截取视口**只添加可预览的图片，不改变相机、选择或几何，发送前不会上传。上传与截图共用最多 5 张、每张 5 MB 的限制，支持 JPEG、PNG、WebP 和 GIF。请选用支持图片和工具的模型。

## 追加任务和阅读

新助手回复按实际响应顺序交替展示文字、工具调用和建议命令，工具详情仍可展开。接受或拒绝仍针对整批预览，不会逐条执行时间线中的建议。重新打开会话后顺序保持不变；旧会话沿用原有分组显示。

执行期间可继续编辑输入，通过**加入待发送**保存追加任务；可以查看或移除尚未发送的条目。整个当前任务及审查结束后，才按 FIFO 顺序执行。停止、失败、切换项目或刷新都会暂停队列；处理保留的建议后，需要主动**继续队列**，不会自动重放。修改任务模式或批准方式只影响之后的任务。

所有消息采用统一的左对齐阅读列。停止请求按钮仅显示图标，位于请求状态右侧。向上滚动，离底部超过 80 CSS 像素时停止自动跟随，工具、图片和 Markdown 的增长也不会强制跳回底部。点击**返回底部**平滑滚动到最新内容并恢复跟随；手动滚动会中止动画，减少动态效果偏好下则直接返回底部。小尺寸的返回按钮在水平方向居中，直接悬浮于对话内容上方，不额外占用底部空间；Modra 响应时显示加载图标，悬浮或键盘聚焦时显示向下箭头。按钮、菜单、引用、审查和队列均支持键盘焦点与触摸操作。

## 本地会话和限制

标题栏的会话菜单可新建、打开、重命名和删除本地会话。新会话及未发送草稿先保留在内存中，首次发送任务或手动保存标题后才入库；当前会话尚未保存时，再点新建不会创建重复空会话。可直接粘贴参考图片，或使用图片选择器，两者共用五张图片上限、格式及大小校验。标题最多 10 个字：发送首条请求时先截取文字（纯图片请求使用图片名），首轮回复完成后，再通过当前配置的服务商、协议与连接方式发起一次独立的文本总结请求。该请求只包含首轮的有限文本，不包含图片、场景或工具详情；失败时保留临时标题，手动改名不被覆盖，重开历史不会再次请求。消息头部显示本地时间，右侧的小图标复制按钮只复制文字，不会替换当前草稿及图片。会话入库后，草稿、图片及待发送任务存储在独立浏览器数据库，不写入原生项目或 glTF。会话列表仅展示当前项目。放弃未保存项目时会清理其临时会话及未引用图片；已保存项目的会话保留。页面退出时尽力清理，中断后遗留的新临时历史会在后续访问、写入租约过期后检查回收，不扫描迁移历史遗留数据。另一个标签页拥有会话写入权时，本页只读。存储拒绝或配额错误会明确提示，内存回退不能持久保存。

Modra 不会悄悄截断历史。安全预算为：语义历史 1 MiB，历史图片 30 MiB，单次服务商响应 4 MiB，每次运行助手正文 512 KiB，单个工具参数或结果 256 KiB。这些是字节安全限制，不保证符合服务商令牌窗口。上下文过大时请新建会话或移除未发送附件；输出过大时会保留已收到内容和有效预览，请先处理待审更改，再请求更小步骤。服务商自身限制可能更小。

悬浮按钮中的机器人以待机眨眼、工作摆动、完成点头和错误摇头区分状态。Modra 打开时，完成状态在 3 秒后回到空闲；窗口隐藏时保留完成状态，直到再次打开。发起新操作会取消旧倒计时。标题栏的最小化按钮仅隐藏窗口，不会中断任务。减少动态效果偏好会关闭动画，保留静态表情与无障碍状态说明。

## 上下文窗口与自动压缩

输入区的圆环指示器可展开查看上下文用量，估算范围包含历史消息、图片、最新场景观察、
工具开销和下一轮输出预留，不代表累计计费量。不同服务商的分词和图片处理方式不同，
因此这些数值均为估算。在 AI 服务设置中展开「上下文设置」，可配置模型输入与输出的
总容量。默认值为保守的 32,768 Token 应用预算，并非自动检测的模型上限；请勿设置为
超过服务商文档中模型实际限制的数值。每轮工具请求为模型输出预留 4,096 Token。

当含输出预留的预计占用达到容量的 80% 时，Modra 会在下次任务开始前，通过当前配置的
AI 服务、协议和连接方式总结较早的任务。总结是独立的、可能产生费用的纯文本请求，
不会携带建模工具或图片原始数据。较大的历史记录会分块、依次总结。当前任务及其工具
调用、结果和后续执行保持完整。完整消息和本地图片仍保留在会话中，仅后续请求使用
摘要；摘要检查点随本地会话保存。已总结轮次的原图不会再次发送，若需使用原图细节，
请重新附加图片。

摘要仅作为历史背景，不作为当前场景的依据。当前的历史更改状态和最近的早期任务计划
会一并提供，仍需查询最新场景；压缩不会应用或重放建模命令。压缩失败或被停止时，不会
覆盖原检查点或删除消息，可重新发送任务重试。压缩可取消，整体最长等待两分钟。
若当前任务本身就超过预算，Modra 会提示上下文超限，而不是静默截断。中间工具轮次也会
检查估算大小；若超限，请拆分为较小的后续任务，或按模型文档调整容量。自动压缩目前
发生在任务边界，不在正在执行的工具轮次中途进行。

自动回收临时历史还需要获得工作区的独占 Web Lock。打开或被冻结的标签页会持续持锁，不会仅因写入租约过期而丢失会话。不支持 Web Locks 的浏览器跳过自动跨页回收，主动放弃当前项目时仍会清理其会话。
