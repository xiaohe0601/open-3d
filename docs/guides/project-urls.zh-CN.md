# 项目地址规则

[English](./project-urls.md)

独立 Web 应用使用 `/projects/:id`。嵌入式 `WorkspaceApp` 默认不接管宿主页面的历史记录，需显式启用 `projectRouting`。

| 地址 | 含义 |
| --- | --- |
| `/` | 打开空项目，并替换为新的临时项目地址。 |
| `/projects/temp-<uuid>` | 尚未保存的工作区；`temp-` 为保留前缀，不是正式存档 ID。 |
| `/projects/<正式ID>` | 从当前浏览器的本地存档中读取项目。 |

## 临时项目与首次保存

临时地址只标识当前内存工作区，不代表已经保存。刷新临时地址会创建新的空项目并生成新的临时 ID，不会恢复之前未保存的场景。存在未保存更改时浏览器会提示离开风险；请先保存项目或导出 open3d 文件。临时 Modra 历史仍按废弃工作区清理规则处理，不能通过临时地址恢复。

第一次成功保存时生成正式存档 ID，并以正式地址**替换**当前临时地址。后续保存更新同一存档。首次保存只关联 Modra 工作区，不重建场景，不清空撤销记录，也不中断正在执行的任务。

新建和导入项目使用新的临时地址。删除当前打开项目的存档后，场景会作为未保存作品保留，并转为新的临时地址。从项目管理中打开另一存档会增加历史记录。

## 切换与错误处理

浏览器前进、后退与从项目列表打开项目共用未保存更改确认逻辑。加载或确认期间，地址保持对应当前显示的场景。取消后保留当前场景和地址；放弃更改或保存并继续后，打开目标项目。新的导航或场景替换会使较早的未完成加载失效，防止旧请求覆盖当前项目。

项目不存在或本地存储不可用时显示错误，保留当前场景。首次通过正式地址打开失败时，地址回退为新工作区的临时地址。加载失败不会自动创建或覆盖存档。

项目链接**不提供跨浏览器、设备、用户或浏览器配置文件的数据共享**。如需传递可编辑作品，请导出 open3d 文件。原生文档 ID 与本地项目存档 ID 是不同概念，路由使用后者。

## 静态部署

构建会将 `public/_redirects` 复制到 `dist/_redirects`，在 Netlify 和 Cloudflare Pages 上将 `/projects/*` 内部重写到 `/index.html`。其他托管服务需配置等效的 SPA 回退，不应重写静态资源或 AI 网关端点。Vite 开发服务器已支持深层链接。
