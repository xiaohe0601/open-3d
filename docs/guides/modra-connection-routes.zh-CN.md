# Modra 连接方式

[English](modra-connection-routes.md)

协议与连接方式是两个独立设置。选择服务商协议、端点和模型后，主动保存所需连接方式。

| 连接方式     | 使用条件                                                                        | 信任边界                       |
| ------------ | ------------------------------------------------------------------------------- | ------------------------------ |
| 直连（默认） | 服务商允许浏览器 CORS、原生协议和必要请求头                                     | 浏览器 → 服务商                |
| Open 3D 网关 | 网站已提供该服务；按提示完成验证                                                | 浏览器 → Open 3D 中转 → 服务商 |
| 自部署网关   | HTTPS 网关地址（仅本地开发允许 HTTP）、可选独立部署令牌、兼容接口和准确网页来源 | 浏览器 → 你选择的中转 → 服务商 |

当 AI 服务商不支持浏览器跨域请求（CORS）时，Open 3D 提供轻量级网关，通过 Cloudflare Workers 转发请求。Cloudflare 提供的额度有限，当 Open 3D 官方网关不可用时，可以选择自部署方案，详见[四步部署指南](../../apps/ai-gateway/README.zh-CN.md#部署网关)。

浏览器首先无凭证访问 `/v1/capabilities`，确认版本、协议和限制兼容，再向 `/v1/relay` 发送原生 JSON 和允许的服务商请求头。上游地址、网关授权使用独立控制头，中转不会将控制头发送给服务商。凭证不会放入 URL；Gemini 只保留原生的 `alt=sse` 查询参数。

使用 Open 3D 网关时，可能需要按提示完成 Cloudflare Turnstile 验证。验证会连接 Cloudflare，但不会向验证服务发送提示词、图片或服务商密钥。取消会停止验证；验证过期或失败后可以重试。直连不加载该验证组件。

仅在运营者显式关闭令牌鉴权（`auth: none`）时可留空网关令牌；Origin 不是鉴权，无令牌公开中转存在滥用风险。

自部署令牌与服务商密钥分别保存在浏览器设置中，支持独立移除；浏览器本地存储不是安全保险箱，页面脚本可以访问。移除本地副本不等于在签发方吊销凭证。切换直连或 Open 3D 网关后，保存的设置不包含自部署令牌字段。

网关访问、策略、大小、兼容性、配置和限流/并发错误与服务商鉴权/额度错误分开展示。仅合适的瞬时错误进入现有的五次连接重试，中转本身不重试、不解析模型内容，也不持久化内容。已开始输出的流中断不会重放。不设服务商主机白名单，兼容的自定义公共 HTTPS 端点可使用相同的四种原生操作；准确网页来源和目标 URL 安全校验仍生效。网关不绕过服务商政策、地域限制或账号授权。

新生成的网关还限制部署级并发和每日准入转发次数。网关每日额度耗尽时，Modra 不自动重试；请等到 UTC 零点、联系网关运营者，或主动选择其他连接方式。此额度与模型服务商的额度无关。独立的上传、响应开始、流式空闲及整体超时配置，以及上线验收清单，见网关部署指南。

网关中转必然经过瞬时内存，并保留短期安全元数据；基础设施和服务商政策仍适用，不能承诺全链路零留存。自部署时需要自行确认运营者、配置和数据安全。详见[隐私与排障](ai-privacy-and-troubleshooting.md)。不承诺永久免费托管或全局费用硬上限。
