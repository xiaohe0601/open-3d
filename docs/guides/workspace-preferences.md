# Workspace Display Preferences

Use the language and theme buttons at the right of the top bar. Display preferences no longer require a settings dialog. Each menu marks the selected preference; press Escape to close it and return focus to its button.

- Language: Follow system, English, or Simplified Chinese. System mode follows the browser language list, using Simplified Chinese for Chinese locales and English otherwise.
- Theme: Follow system, Light, or Dark. System mode follows changes to the operating-system color scheme. An explicit choice remains active until Follow system is selected again.

Changes apply immediately without recreating the modeling viewport. Preferences are stored in this browser, separately from saved projects and exported files; they do not modify the document or its undo history.

The top bar groups project management, import/export and save separately from undo and redo. Add object is in the Objects panel heading and opens a compact menu beneath the button, offering Box, Sphere and Cylinder. On narrow screens, these actions occupy a second row while language, theme and project identity stay on the first row. Narrow-screen toolbars use consistent compact 32px controls instead of stretching buttons based on screen width. AI provider configuration remains available inside Modra.
