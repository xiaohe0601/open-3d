## Dependency Boundaries

- `model-core` owns serializable document semantics, stable identities, validation, mesh topology, commands, queries, and history. It imports no renderer, browser persistence, or AI packages.
- `viewport-three` owns Three.js projection and picking. `three-mesh-bvh` may be added only if prototype measurements show a meaningful benefit for the representative scenes.
- `projects` owns native document serialization, migrations, IndexedDB adaptation, and glTF translation. It must not expose Three.js objects as document state.
- `ai` owns provider configuration and orchestration. It can invoke only the public command/query contracts and must not contain a server or proxy requirement.
- All external dependencies remain replaceable behind these package boundaries. No WASM dependency is selected at this stage.

## Validation Still Required

- Record exact transitive licenses and dependency graph during release verification.
- Capture production build bundle contribution for React, Three.js, icon usage, validation, and selected AI modules; do not infer emitted size from the package installation footprint.
- Verify Vite+ clean install, task graph, and CI behavior with the selected pnpm version; root task configuration is now wired but must pass the full local pipeline.
- Verify browser compatibility against the declared Chrome, Edge, Firefox, and Safari matrix. Registry metadata and a successful local build do not establish browser compatibility.
- Exercise Three.js and optional BVH interaction on the primitive, editable-quad, and dense-mesh fixtures on both reference device tiers.
- Verify glTF-Transform round trips hierarchy, transforms, mesh indices, and supported material factors; reject or report unsupported content. The local golden fixture and GLB/glTF round-trip coverage pass; multi-browser and release-device verification remain outstanding.
- Test AI SDK requests against representative compatible endpoints for browser CORS, streaming, cancellation, and tool-calling variations. The local mock-fetch suite verifies the SDK adapter contract only; it does not establish live-provider compatibility. Do not transmit credentials through an untrusted backend.
- Measure IndexedDB save/load latency and failure behavior with representative project sizes in each supported browser family.
- The local lab does not yet contain Chrome, Firefox, or a minimum-tier device. Foundation review accepted this coverage gap under an explicit user-approved scope exception; full matrix and both-tier validation remain release requirements and must not be claimed as completed by the prototype.
